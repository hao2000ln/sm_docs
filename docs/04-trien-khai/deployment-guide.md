# Hướng dẫn Triển khai

## 1. Yêu cầu môi trường
* Node.js v18+ hoặc v20+ LTS
* Docker Engine 24.0+

## 2. Các bước chạy môi trường Production

```bash
# Đóng gói static build
npm run build

# Chạy thử nghiệm local
npm run serve
```
